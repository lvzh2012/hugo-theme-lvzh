This is a demo site for the **Lvzh** Hugo theme.

Lvzh is a minimal editorial theme inspired by warm cream palettes and clean typography. It features serif headings, sans-serif body text, and a terracotta accent color for a professional yet inviting reading experience.

## Features

- Responsive design for all screen sizes
- Table of Contents with scroll spy
- Reading progress bar
- Cover image support
- Pagination
- Back to top button
- CJK (Chinese/Japanese/Korean) language support
- Mobile hamburger menu
- Sidebar article navigation on homepage
